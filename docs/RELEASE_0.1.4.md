# 麦之诗(界面风格) 0.1.4 预发布

插件列表和市场展示改用用户提供的小人头像。图标保留原构图、颜色与米白色底板，仅将外侧四角的黑色区域改为透明，等比缩小为 256×256 PNG，符合宿主的 512KB 限制，完整包含在安装包内。

前端载荷、主页和主题选择图标沿用 0.1.3，兼容范围仍为 **MaiBot 1.3.18 + Plugin SDK 2.19.0 + maibot-dashboard 1.9.12**。下载 `maizhishi-theme-0.1.4.zip`，校验值见 `SHA256SUMS.txt`。

插件会写入、还原插件目录外的 Dashboard 文件。更新前先禁用并确认还原，再更换版本；旧 `local.maizhishi-theme` 测试版须先完整卸载，不得与正式 ID 同时加载。详情见 [安装与恢复说明](INSTALL.md)。

保留 [0.1.3 发布说明](RELEASE_0.1.3.md) 中的功能、验证与限制。此版本尚未上架市场；游戏资源等素材的分发许可和两项旧版依赖许可对应关系仍保留既有待核对记录。新图标的原始文件及缩小处理记录见 [图标来源](plugin-icon-source.json)。
