# 麦之诗(界面风格) 0.1.3 预发布

安装后在 **WEBUI设置 → 外观 → 界面风格** 中选择第四主题 **麦之诗**。保留原三种主题和主页功能，提供青白、夜蓝两套配色、立绘进化切换及音效、主题导航和顶栏小人交互。

这是首个 GitHub 预发布版本，尚未上架插件市场。

## 本版修复

- 即时对话发送图标居中，固定为 17px。
- 共用按钮框使用完整原生纹理的九宫格绘制，修复发送按钮中段断口及顶栏接缝色差。

## 安装与兼容

仅支持 **MaiBot 1.3.18 + Plugin SDK 2.19.0 + maibot-dashboard 1.9.12**，并要求原版前端的 224 个文件指纹匹配。不同版本或被其他程序改过的文件会拒绝覆盖。

下载 Release 附件 `maizhishi-theme-0.1.3.zip`，在 **插件扩展 → 更多操作 → 从 ZIP 安装插件** 中安装，按宿主提示重启或启用，刷新页面后选择主题。附件 `SHA256SUMS.txt` 提供安装包校验值。预构建包包含完整前端载荷及对应源码，安装无需 Node.js。

插件会在加载、卸载时写入、还原 **插件目录外的 Dashboard 静态文件和目标所有权记录**，运行用户需要相应目录的写权限。使用固定指纹、私有备份、共享锁与事务恢复；没有采用宿主通用主题注册接口。不支持只读安装或本地 Dashboard 覆盖模式。

已安装旧测试 ID `local.maizhishi-theme` 的用户，必须先禁用、确认还原并卸载旧插件，再安装正式 ID `github.littlesleepy.maizhishi-theme`。新旧 ID 不得同时加载，不能挪用旧备份。更新版本前同样先禁用并确认还原。第四主题偏好仅保存在当前浏览器。

正常禁用或卸载后刷新页面，恢复原三个主题。异常情况先保留备份，按 [安装与恢复说明](INSTALL.md) 操作。市场一键升级尚未验证。
