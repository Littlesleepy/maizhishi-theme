# 麦之诗(界面风格) 0.1.5

首个正式版，适配 **MaiBot 1.3.18 + Plugin SDK 2.19.0 + Dashboard 1.9.12**。

安装后在 **WEBUI设置 → 外观 → 界面风格 → 麦之诗** 中选择主题。保留原三个主题及主页功能，提供青白与夜蓝配色、立绘进化切换和音效、主题导航及顶栏小人交互。

## 本版内容

- 沿用 0.1.4 的前端、主题资源和四角透明插件图标；即时对话发送按钮和顶栏按钮使用已修复的完整原生边框。
- 整理 README 使用说明，安装包包含完整对应源码、锁文件、资源来源及第三方声明。

## 安装与更新

下载附件 `maizhishi-theme-0.1.5.zip`，校验值见 `SHA256SUMS.txt`。通过 **插件扩展 → 更多操作 → 从 ZIP 安装插件** 安装，按提示启用或重启，刷新页面后选择主题。

插件会修改插件目录外的 Dashboard 前端文件，需要相应目录写权限，并校验原版文件指纹。更新前先禁用并确认还原，再更换版本；正常禁用、卸载后恢复原版前端。旧 `local.maizhishi-theme` 测试版应先还原并卸载，不得与正式 ID 同时加载。异常情况保留备份，按 [安装与恢复说明](INSTALL.md) 处理。

兼容范围仅限上列固定版本；MaiBot 1.4.3 适配将在后续版本提供。市场收录以官方审核结果为准，市场一键升级尚未验收。完整限制见 [兼容说明](COMPATIBILITY.md)。
