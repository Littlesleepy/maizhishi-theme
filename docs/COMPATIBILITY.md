版本号相同但文件指纹不同也会拒绝覆盖。升级宿主、SDK 或 Dashboard 前，应先禁用并确认还原；新版本需要单独适配、构建及验收，不能只扩大 manifest 版本范围。

## 安装方式

运行用户需具备 Dashboard 静态目录和包目录的写权限。不支持只读系统包、设置了 `MAIBOT_WEBUI_USE_LOCAL_DASHBOARD` 的本地覆盖模式，也不支持多个实例用不同私有备份同时持有同一个静态包。共享锁及目标所有权记录位于静态目录外。

插件不修改宿主 Python 实现和模型、聊天平台配置。启停时会写入、还原插件目录外的 Dashboard 文件，市场审核时应明确披露此行为。

## 已完成的验证

- 固定完整官方宿主与真实 Runner：安装、启用、重启、禁用、卸载、不同载荷受控更新、Runner 异常退出后的幂等加载。
- 原始前端 224 个文件完整还原；载荷校验、冲突拒绝、私有备份恢复、共享目标并发保护。
- 浏览器原三个主题及第四主题选择、刷新保留、深浅配色。第四主题偏好仅在当前浏览器保存，原后端继续接收 0/1/2。
- WO4 既有实例已安装 0.1.0，并核验服务健康、真实加载日志和公开静态文件指纹；本次发布整理没有替换线上版本。

0.1.1 只整理打包、展示元信息与文档，沿用相同前端载荷；本轮另外验证自包含源码构建和 ZIP 重打包。既有实际安装验收不等于 0.1.1 已再次部署到线上。

- 尚未完成市场收录和市场远程自动升级，不承诺官方市场一定接受这种前端补丁方式。
