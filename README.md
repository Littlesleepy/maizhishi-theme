# 麦之诗(界面风格)

以《影之诗》的美术风格装点界面，淡金边框搭配青白与夜蓝两套配色。

## 使用条件

- **MaiBot 1.3.18 + Plugin SDK 2.19.0 + Dashboard 1.9.12**。
- 使用原版 Dashboard 前端文件。
- 运行 MaiBot 的系统用户须能写入 Dashboard 静态目录及其上一级包目录。

## 下载安装

1. 前往 [GitHub Releases](https://github.com/Littlesleepy/maizhishi-theme/releases)，下载附件中的 `maizhishi-theme-版本号.zip`。
2. 在 WebUI 中打开 **插件扩展 → 更多操作 → 从 ZIP 安装插件**，选择下载的安装包。
3. 安装完成后，按宿主提示重启或启用插件，再刷新 WebUI。

## 启用主题

进入 **WEBUI设置 → 外观 → 界面风格 → 麦之诗**。

- 点击顶栏 **进化**：切换为深色主题及进化后立绘。
- 点击顶栏 **返回**：切换为浅色主题及进化前立绘。

主题选择仅保存在当前浏览器；更换浏览器后需重新选择。

## 更新与卸载

**更新：** 先禁用插件，刷新并确认恢复原三个主题，再卸载旧版、安装新版，按提示启用或重启并刷新页面。

**卸载：** 先禁用插件，刷新并确认恢复原三个主题，再通过插件扩展卸载。

**旧测试版迁移：** 曾安装 `local.maizhishi-theme` 的用户，须先禁用、确认还原并卸载旧测试版，再安装新版。新旧插件不能同时启用，不要复制或覆盖旧备份。

## 遇到问题

- **看不到麦之诗主题：** 确认插件已启用，按宿主提示重启，再刷新 WebUI。
- **安装失败：** 检查版本是否符合要求、Dashboard 是否为原版，以及运行用户是否具有所需目录的写权限。
- **安装或还原报错：** 保留插件数据，按 [详细安装与恢复说明](docs/INSTALL.md) 处理。
